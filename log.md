To start off working with touch designer I started by watching a series on youtube to help me learn the basics. I took the following notes: 

I = Go in 

U = Go out 

Tab = Op Create dialog 

H = Home - view all ops 

After clicking tab these are the options for operators: 

1. Tops = Texture Operators - texture for images and videos

2. Chops = Channel Operators - signals/communication (Numeric data channels) - continuous feed

3. Dats = Data Operators - tables with numbers/text

4. Sop = Surface operators - 3D Geometry/surfaces

5. Comps = Component Operators - 
a. panels - buttons, sliders, user interactors 
b. container - holds and groups elements of user interfaces and holds other operators
c. 3D objects - Camera, light for 3D 
d. Other - Window = final product - big screen or projector. Animation = Key frames. 

6. Mats = Material Operators - processing materials that get applied to 3D renders. 

Plus button = viewer active - interacting with content inside on drag - only affects view 

Parameters = values that are available and can be changed for each given operator to control its functionality.

P = opens/closes parameters window

Don't use step backward ->

Double Click = Info - Information about the operator. Data based on operator - or 'i' in the parameter window

Network = hold operators - can go inside an operator to se another network. 

Pane options = (top right) ->
a. split left/right - splits into 2 workspaces 
b. Split top/bottom - splits into half

Option z - close pane

Option [ - split left/right

Option ] - split top/bottom

Pane layout - top left - template options 

? No background - in parameter window - help button - info about operator
